# Historical pose-animation prompts

This file records an earlier image-animation experiment. The released timer uses continuous 3D models and skeletal motion; these pose atlases are excluded from the production build. See [current artwork notes](ARTWORK.md) and the [asset ledger](../ASSETS.md) for the shipping implementation.

The following text preserves the generation prompts as historical records, including their original references to production assets. Each experimental action used a 24-pose sheet. These descriptions are not instructions for maintaining the current renderer.

## cat-scratch.webp

Production sprite animation atlas in the exact painted style and cat identity of the reference. ONE image containing EXACTLY 24 frames in a strict 6-column × 4-row regular grid, chronological order left to right, then top to bottom. All cells exactly equal size, same fixed camera, identical character scale, consistent anchor at bottom center of each cell; keep all painted pixels safely inside each cell with 10% empty margin. The cat stands on its two planted hind paws, body upright with a natural curved spine, tail balancing behind. One forepaw reaches diagonally upward to the RIGHT, spreads three visible claws against an imaginary glass pane, makes a deliberate short DOWNWARD scratching stroke, then folds naturally at elbow and shoulder to retract, then reaches again. The other forepaw rests against glass for balance. Clearly different anatomically valid sequential poses. Body mass remains supported, no floating limbs. Claws clearly visible during contact frames 8 through 15. End pose returns to first pose. Preserve the reference's anatomically credible domestic shorthair tabby-and-white cat, small green eyes, vermilion beret, ochre/cream/forest palette, rich oil-and-gouache brushwork and textured fur. Each frame is an actual distinct drawn pose, not a warped duplicate. Genuine transparent background everywhere outside the character. No floor, props, clocks, captions, numbers, cell borders, labels, or other animals. Clean separate silhouettes, no touching between cells. Landscape 1536×1024 composition.
